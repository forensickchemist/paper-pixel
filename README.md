# Paper Pixel Online Bookstore

Paper Pixel Online Bookstore is a full-stack online bookstore application developed as a Capstone 3 project.

The application allows customers to browse and search for books, view book details, manage their shopping cart, and place orders. Administrators can manage books, authors, categories, book formats, inventory, and orders through an administrative dashboard.

## Technology Stack

### Frontend
- Vue 3
- Vite
- Vue Router
- Pinia
- Axios
- Bootstrap 5

### Backend
- Node.js
- Express
- MongoDB
- Mongoose
- JWT
- Cloudinary

## Project Structure

```
paper-pixel-online-bookstore/
├── frontend/
├── backend/
└── README.md
```

The frontend and backend are maintained as separate applications.

## Main Features
- User registration and authentication
- Role-based access control
- Book catalog and book details
- Book search
- Authors and categories
- Multiple book formats
- Shopping cart
- Order management
- Administrative dashboard
- Inventory management
- Cloudinary image storage
- REST API

## API Documentation
The project's REST API is documented using Postman.


## Project Status
The backend is deployed at AWS Lambda
